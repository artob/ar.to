Arto's Notes re:

PCs

  • Components
  • Peripherals

Components

Essential

  • power supply (PSU)
  • motherboard (mobo) with an integrated NIC and optional audio/video support
  • processor (CPU) (with heatsink or cooler) compatible with the mobo’s socket
  • RAM memory compatible with the mobo
  • internal persistent storage, such as an SSD or a HDD

Optional

  • chassis (case)
  • graphics processing unit (GPU)
  • optical (DVD or Blu-ray) drive

Peripherals

Essential

  • monitor
  • keyboard
  • mouse

Optional

  • speakers
  • webcam
  • printer
  • scanner
