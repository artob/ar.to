# Arto's Projects

My open-source projects & initiatives.

- [ASIMOV](https://ar.to/projects/asimov.md) (2024): A polyglot development platform for trustworthy personal intelligence.
- [Readmer](https://ar.to/projects/readmer.md) (2026): Composes `README.md` files from Liquid or Jinja2 templates.
- [Edky](https://ar.to/projects/edky.md) (2026): Converts Ed25519 public keys between various encoding formats.
- [RDF.rs](https://ar.to/projects/rdf.rs.md) (2024): A Rust framework for working with RDF knowledge graphs.
- [Dogma](https://ar.to/projects/dogma.md) (2017)
- [Conreality](https://ar.to/projects/conreality.md) (2015)
- [Dydra](https://ar.to/projects/dydra.md) (2011): The first graph database as a service (GDBaaS), a cloud-hosted RDF triple store with a SPARQL query engine.
- [Unlicense](https://ar.to/projects/unlicense.md) (2010): A template for disclaiming copyright monopoly interest in software you've written.
- [RDF.rb](https://ar.to/projects/rdf.rb.md) (2009): A pure-Ruby library for working with RDF data.
- [Bitcache](https://ar.to/projects/bitcache.md) (2007): A distributed content-addressable storage (CAS) system.
- [Drush](https://ar.to/projects/drush.md) (2006): A command-line shell and scripting interface for Drupal.
- [Boost](https://ar.to/projects/boost.md) (2006): Static page caching for Drupal.
